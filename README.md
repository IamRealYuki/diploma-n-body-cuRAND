ВКР на тему: Генерация функции распределения гравитирующих систем с использованием библиотеки cuRAND
Проект разрабатывался в среде Google Collab. Для запуска необходимо: 
1) установить зависимости: 
!pip install pycuda
!pip install numpy
!pip install pybind11
2) загрузить файлы в среду google collab
3) скомпилировать cuda ядро в бинарный формат: !nvcc -arch=sm_75 -cubin energy_kernel.cu -o energy_kernel.cubin
4) скомпилировать программу-генератор: !nvcc -arch=sm_75 generate.cu -o generate -lcurand -lcuda
5) скомпилировать библиотеку для python-скрипта симуляции, которая строит октодерево: 
!g++ -O3 -Wall -shared -std=c++11 -fPIC \
    $(python3 -m pybind11 --includes) \
    octree.cpp \
    -o octree_lib.so
6) Запустить выполнение всех скриптов и программы-генератора через pipe: !./generate $((1024*50)) | python3 simulate.py | python3 viewer.py 10 60
generate принимает как входной аргумент число точек, которые должны быть сгенерированны (по умолчанию 1024 * 128 или 131.072)
скрипт визуализации viewer.py принимает два аргумента: длительность видеофайла и число кадров в секунду (по умолчанию 10 и 30). 
Из-за особенностей работы google collab, каждый кадр отдельно создаётся и записывается в видеоролик

Приложение генерирует точки, которые задаются распределением Камма: 
$$
1 - r^2 - v_r^2 - v_t^2(1 - r^2) \leq 0
$$

Затем, на каждом шаге приблизительно вычисляется взаимодействие частиц, с помощью алгоритма Барнса-Хатта, после чего новые координаты точек уходят в отрисовщик.
